# 괴산점 공용 장부 연결 안내 (사장님용)

**KT 텔나라네트웍 괴산점** 개통장부·가망고객 밴드 두 앱이 함께 쓰는 **구글 시트 + Apps Script** 설정입니다.
한 번만 하면 되고 5~10분이면 끝납니다. 순서대로만 하시면 됩니다.

- 이 폴더의 **`Code.gs`** ← 이 파일 하나만 시트에 붙여넣습니다. (개통장부 + 밴드 공유가 한 파일에 다 들어 있습니다)
- 매장 접속 PIN: **0315** (이미 넣어 두었습니다 — 직원 폰이 처음 연결할 때 한 번 넣는 값)
- 관리자 PIN: **사장님 지정 6자리** (2026-11-27 변경 — 값은 `Code.gs` 의 `ADMIN_PIN` 과 같아야 합니다)
- 사장님 이름(추방 불가): **방지유** (이미 넣어 두었습니다)
- 직원 명단: **방지유 · 우광걸** (이미 넣어 두었습니다)

---

## 0단계 — 매장 PIN (이미 정해져 있습니다 · 확인만)

`Code.gs` 맨 위에 괴산점 값이 이미 들어가 있습니다.

```js
var STORE_PIN    = '0315';               // 괴산점 전용 매장 PIN
var ADMIN_PIN    = '……';                 // 사장님(관리자) PIN — 개통장부 앱 설정과 같아야 함
var STAFF_NAMES  = ['방지유', '우광걸'];  // 직원 명단
var OWNER_NAMES  = ['방지유'];            // 사장님(추방 불가)
```

**고칠 것이 없으면 1단계로 넘어가시면 됩니다.** 매장 PIN(`0315`)은 직원 폰이 처음 연결할 때 한 번 넣는 값이고, 개통장부 앱의 「매장 PIN」 칸과 같습니다.

## 1단계 — 새 구글 시트 만들기

1. https://sheets.google.com → **빈 스프레드시트** → 이름을 `괴산점 개통장부` 로 바꿉니다.
2. 위쪽 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
   (폰 시트 앱에는 이 메뉴가 없습니다. **이 단계만 PC나 태블릿 데스크톱 모드**에서 하시고, 나머지는 폰에서도 됩니다.)

## 2단계 — 스크립트 붙여넣기

1. 새 창에 코드가 조금 적혀 있으면 **전부 지웁니다** (Ctrl+A → Delete).
2. 이 폴더의 **`Code.gs` 내용 전체**를 복사해 붙여넣습니다.
3. 위쪽 **💾 저장**(Ctrl+S) → 프로젝트 이름은 `괴산점 장부 연동` 정도로.

## 3단계 — 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 왼쪽 톱니바퀴(유형 선택) → **웹앱**.
3. 아래처럼 설정합니다.
   - 설명: `괴산점 공용 저장소`
   - **실행 대상: 나**
   - **액세스 권한: 모든 사용자** ← 이게 아니면 직원 폰에서 구글 로그인 화면이 떠서 연결이 안 됩니다
4. **배포** → 구글 계정 권한 요청이 나오면
   `권한 검토 → 계정 선택 → 고급 → (안전하지 않음) 이동 → 허용`.
5. 나오는 **웹앱 URL**(`https://script.google.com/macros/s/AKfy…/exec`)을 복사합니다.
   → 이 주소를 저(Pickle)에게 주시면 두 앱에 그대로 넣어 드립니다.

## 4단계 — 잘 되는지 확인

브라우저 주소창에 아래를 넣어 봅니다. (`주소` 는 3단계에서 받은 `/exec` 주소, PIN 은 매장 PIN `0315`)

```
주소?pin=0315&action=ping
```

- `{"ok":true,...}` 가 보이면 성공입니다. 시트에 `전체_통합` 탭이 자동으로 생깁니다.
- `매장 PIN 이 아직 정해지지 않았습니다` → 0단계를 안 하셨습니다. `Code.gs` 의 `STORE_PIN` 을 채우고 **저장 → 배포 → 배포 관리 → 연필(✏️) → 버전: 새 버전 → 배포**.
- `매장 PIN이 맞지 않습니다` → 주소의 PIN 과 `Code.gs` 의 `STORE_PIN` 이 다릅니다.

## 5단계 — 앱에 연결

- **개통장부 앱**: `더보기 → 공용 장부 연동 (Google 시트)` → 연동 주소에 `/exec` 주소, 매장 PIN `0315`, 내 이름 `방지유` (직원 폰이면 그 직원 이름) → **연결 테스트** → “연결 성공! 시트에 N건이 있습니다.” → **저장**
- **가망고객 밴드 앱**: 따로 설정할 것이 없습니다. 같은 주소가 앱 안에 들어가 있어서, 배포가 끝나면 **30초 안에 스스로** 실시간 공유를 켭니다.

## 시트에 생기는 탭 (지우거나 고치지 마세요)

| 탭 | 내용 |
|---|---|
| `전체_통합` | 모든 개통 기록 (앱이 쓰는 본 표) |
| `담당_방지유` · `담당_우광걸` | 직원별 보기 (FILTER 수식 — 자동) |
| `_접속기기` (숨김) | 앱을 연 기기 목록 · 승인 상태 |
| `_차단` (숨김) | 추방한 기기·직원 |
| `_밴드공유` (숨김) | 밴드 앱의 고객 상태·메모·예약·댓글·글 |

## 자주 막히는 곳

| 증상 | 원인 / 해결 |
|---|---|
| 연결 테스트가 “응답을 해석하지 못했습니다” | 액세스 권한이 **모든 사용자**가 아님 → 새 배포로 다시 |
| 브라우저에 구글 로그인 화면이 뜸 | 위와 같음. “모든 사용자”로 배포해야 로그인 없이 동작 |
| 시트에 안 쌓임 | 배포 주소가 `/exec` 로 끝나는지 확인 (`/dev` 는 안 됩니다) |
| 코드를 고쳤는데 반영이 안 됨 | **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소는 그대로) |
| 직원 폰이 “사장님 승인 대기 중” | 사장님 폰에서 관리자 PIN → `더보기 → 직원 · 기기 관리` → 그 기기 **승인** |
